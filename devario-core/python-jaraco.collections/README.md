# python-jaraco.collections

Pinned upstream pure-Python wheel from [PyPI](https://pypi.org/project/jaraco.collections/5.2.1/), verified by SHA-256.
This bootstrap recipe uses python-installer alone to break the dependency cycle
through the already published python-build and python-setuptools packages.
No compiled extension or interpreter-specific bytecode is supplied by the wheel.

See [build order](../../JSONSCHEMA-BUILDS.md).
